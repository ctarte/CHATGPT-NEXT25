# NEXT25 Phase 21 — Blueprint Intelligence & Report Engine™
Adds an explicit, non-diagnostic Personality & Work-Style Profile™ with 14 directional dimensions; evidence/confidence-aware signal contracts; friction and opportunity-redesign logic; structured Blueprint JSON schema; 2–3 deep Opportunity Brief architecture; income-context, customer/employer discovery and source metadata standards; report compilation contract; and versioned work-style/report records.

Personality/work style never acts alone. It is combined with interests, skills, experience, energy, values, lifestyle, income objectives, time, constraints, risk and deferred aspirations. No simplistic fixed personality type selects a career.

The approved structured Blueprint is the canonical content record. PDF is a presentation/delivery format generated only after human QA. Phase 22 should implement the branded PDF renderer/research evidence pipeline and test a complete fictional Blueprint end to end.
