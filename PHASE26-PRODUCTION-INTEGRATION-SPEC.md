# NEXT25 Phase 26 — Production Integration & First Synthetic Customer™
Phase 25 established launch gates. Phase 26 builds the first deterministic end-to-end rehearsal.

Fictional customer: Elena Brooks, 59. Her scenario deliberately contains contradictory preferences, hard constraints, a missing answer, an income objective and selling friction so the system must clarify, redesign and research rather than guess.

Adds:
- frozen synthetic assessment and evidence-backed signal fixtures;
- nine matched possibilities across Strong / Adjacent / Overlooked;
- research-task fixtures;
- 25-event dry-run lifecycle;
- exception tests for duplicate payment, missing answer, unsupported income, stale approval and wrong PDF;
- synthetic run database evidence model and API scaffolds;
- integration order, provider checklist, runbook and acceptance tests.

This phase is honest about the boundary: it proves the orchestration contract locally; it does not claim external production providers are connected. The next implementation step requires actual staging provider configuration and secrets outside the public GitHub repository.
