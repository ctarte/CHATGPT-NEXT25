# Customer-Initiated Idea Standard
Ask: “Is there something you've secretly thought about doing that NEXT25 hasn't mentioned?”

Treat a customer idea as first-class input, not a side note. Analyze it with the same rigor as a system-originated possibility: work reality, work-style/lifestyle fit, transferable assets, friction, buyers/employers, economics, market access, licensing/regulatory questions where material, first 30 days, 90-Day Experiment™, poor-fit evidence and current sources.

Never use system ranking to dismiss a customer's idea. If evidence suggests friction, explain the friction and offer redesign/testing. The customer decides.
