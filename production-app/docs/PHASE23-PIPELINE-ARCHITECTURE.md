# Assessment-to-Blueprint Generation Pipeline™
The production pipeline is staged, versioned and auditable rather than one large AI prompt.

1. assessment_frozen — immutable snapshot after customer completion.
2. signals_extracted — explicit answers become directional signals + reason codes; missing data stays missing.
3. workstyle_built — 14-dimension Personality & Work-Style Profile™.
4. matched — private matcher produces Strong / Adjacent / Overlooked candidates with friction.
5. briefs_selected — select 2–3 sufficiently distinct top candidates for deep research.
6. research_pending — create claim/evidence tasks for income, market access, licensing and implementation.
7. research_complete — all required time-sensitive claims have source/as-of metadata or are explicitly marked unknown.
8. draft_generated — structured Blueprint assembled from versioned artifacts.
9. qa_pending — automated depth/evidence checks + human reviewer.
10. approved — human approval freezes customer-facing content.
11. rendered — branded PDF generated server-side and stored privately.
12. delivered — authenticated customer can view/download.
blocked — any stage can stop rather than guess.

Core rule: a missing answer, uncertain occupation mapping or incomplete regulatory fact must create a question/research task—not a confident invented conclusion.
