# Reviewer Operations Runbook
Start in Queue. Open only assigned/authorized cases.

1 Verify assessment is frozen and customer identity/version is correct.
2 Read next-chapter summary before scores.
3 Inspect signal evidence and low-confidence/missing areas.
4 Compare nine possibilities; reject repetition and hidden constraint conflicts.
5 Review top 2–3 Opportunity Briefs against Depth Standard.
6 Inspect every material current claim: source, date, geography/jurisdiction, limitation.
7 Request research when evidence is incomplete; never patch uncertainty with confident prose.
8 Run QA rubric and record findings.
9 Approve only the exact content version reviewed.
10 Render approved PDF; verify checksum/version/page output.
11 Release only when entitlement/consent/private-storage checks pass.
12 Record follow-up experiment cadence; customer remains decision-maker.
